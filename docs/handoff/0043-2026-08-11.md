## 2. How to ground a case — do not skip this

A `primary_cite` must be the provision that *answers* the question, verified to resolve to a phillycode document with non-empty content. The method:

```sql
select d.section, left(regexp_replace(d.content,'\s+',' ','g'), 400)
from document d where d.source='phillycode' and d.section = '<candidate>';
```

Read the content past the ancestor prefix (`Philadelphia Code, Title 14 > 14-700 (...) > ...`) to confirm the caption matches the question. The prefix is long; the first ~80 chars are useless for identification.

**This matters more than it looks.** ADR-0078's probe table named the wrong target twice and corrected itself (ADR line 131). Phase A found a third: `14-802` holds a document with **zero text**, so it cannot rank on any query and the substantive content is in `14-802(3)(a)[1]#table1`. Three mis-specified targets in a three-row table is the base rate for guessing. A case with unreachable ground truth does not measure a weak arm — it measures nothing, invisibly.

The loader already refuses the two corrupting shapes (answerable case with no ground truth; refusal case naming a cite). Reachability against the corpus is the harness's job at run time — **not** a CI test: CI provisions a fresh testcontainer with no corpus, so such a test fails for the wrong reason. `ground_truth_cites()` and `UNREACHABLE_GROUND_TRUTH` in `ask_loader.py` exist for the harness to use.

## 3. Signed decisions (D1–D3, with amendments)

- **Metrics:** primary-cite hit rate, citation precision, retrieval presence, retrieval position, refusal correctness, latency, tokens. Presence and position are tracked separately from citation so "retrieval failed" is distinguishable from "retrieval succeeded and the model ignored it".
- **Human rubric:** side-by-side transcript (question, both answers, both citation sets, both contexts) for the owner. The session does not score answer quality.
- **Cutover criteria — all must hold on the 22 shared cases:**
  1. Primary-cite hit rate **strictly ≥** incumbent (no tolerance — amended from the proposed −1).
  2. Citation precision ≥ 0.70 and not >10pp below incumbent.
  3. Refusal correctness ≥ incumbent and ≥ 4/5 absolute.
  4. p50 latency ≤ 1.5× incumbent, p95 ≤ 2×.
- Full-corpus wins count in favour but **cannot excuse a shared-subset loss**.

## 5. Phase A results worth carrying

Two defects found only by running against the real 21,512-document corpus, both fixed in `8ef1fbc`:

- **District spelling.** Parcels store `RSA5`; the code writes `RSA-5`. Supplement lookup matched nothing for 7 of 8 districts. `ICMX` worked only because its name has no hyphen. Now searches both spellings.
