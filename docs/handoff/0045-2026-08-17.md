### The three that mattered most

**Ingestion had been dead for 50 days.** ARQ's default `job_timeout` is 300s and `WorkerSettings` never set one; `ingest_all` was killed inside its first two datasets every night. It was silent because ARQ cancels with `asyncio.CancelledError`, which inherits from `BaseException`, so `run_loader`'s `except Exception` never recorded it. Fixed with per-job timeouts and explicit cancellation recording.

**Comps counted foreclosure auctions as market sales.** Sheriff's deeds were ~44% of a typical comp set, dragging the median vacant-lot estimate down ~33%. Median estimate $28,966 → $46,604; range 7.0× → 4.4×; parcels with no estimate 27 → 6.

**The opportunity score contradicted its own recommendation.** 10,867 parcels were told "the deal does not carry itself" while scoring 84.2 average — above the 80.3 of lots recommended for investigation — and the score is the sort key for saved-search alerts. Economics now scales the blend: `economics_unattractive` above 70 fell 9,619 → 9, `strong_candidate` untouched at 664.

## 7. Review-smell ledger — five specimens, one batch

Every defect this session was found by **verifying the effect rather than reading the report**. None was caught by a gate.

1. **The self-confirming test** — three decision tests pinned `deal_infeasible=True` with a 25% margin, arithmetically impossible. Coverage-shaped, asserting nothing reachable.
2. **The masked gate** — `make typecheck 2>&1 | tail -2 && git commit` takes `tail`'s exit code. A mypy failure committed anyway. Fixed structurally: `make lint` now mirrors CI, and gates run bare with exit codes checked.
3. **The guard that dies when it fires** — resolved: inverted at step 6, not deleted.
4. **The known trap that re-arms** — `CAST(:param AS date)` under asyncpg. Written twice in one day, an hour apart, in different files. Countered by `core/tests/test_sql_bind_traps.py`, verified by reintroducing the trap.
5. **Work that reports success while achieving nothing** — the ARQ outage; `_stale_datasets` returning `[]` on error so a broken check read as healthy; `case_status` ingesting 343,083 rows into a column three of four layers discarded.

The rule earned from #5 is now in `CLAUDE.md` §12: *a new ingested column is not done until a test carries a value the whole way, calling the real mapping functions — and the test must fail when the column is removed.* Mine did not, which cost three re-ingests.
