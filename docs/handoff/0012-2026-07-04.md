## What shipped this session

- **Report → dossier PDF + tier gate (`3ddadcf`, ADR-0044 follow-ups).**
  - `report_access(tier)` added to `accounts/tiers.py` (= `FEED_TIERS`, i.e. Pro/Investor/
    Enterprise), mirroring `feed_access`/`sheriff_calendar_access`/`top_plays_access`. The report
    endpoint (`GET /parcels/{id}/report`) now raises `QuotaExceededError` (**429**) for free tier,
    before the key check. Free tier keeps the cheap Haiku Snapshot; paid tiers get the Sonnet memo.
  - `render_dossier_pdf` gained an optional `report: ParcelReportResult` param and renders an
    **"Investment report"** section (headline → section bodies → recommendation, with a confidence
    tag). `build_parcel_dossier` passes it through.
  - `_resolve_report(...)` extracted in `api/parcels.py` — one verdict-scoped cache-read → draft →
    cache path, **shared** by the report endpoint and the dossier endpoint. The dossier embeds the
    memo **only** when `report_access(tier)` **and** an Anthropic key is configured; otherwise it
    silently omits it (dossier stays free + fast for everyone). So a Pro+ dossier download carries
    the memo at no extra generation cost after the first draft.
  - **Robustness fix:** `AnthropicGenerator` now builds its `AsyncAnthropic` client **lazily** (via
    a cached property, on first `.generate()`). The dossier route resolves `get_generator` for
    *every* caller, and `AsyncAnthropic(api_key=None)` raises at construction — this would have
    500'd free/keyless dossier downloads. Construction is now inert; the key is still required to
    actually generate (and is checked upstream).
  - ADR-0044 consequences updated: both follow-ups marked done; deferred narrowed to portfolio
    reports + credit-metered (vs tier) gating.
- **Frontend upgrade CTA (`4a7066a`) + spec (`32981b5`).** `ReportPanel.vue` now has three states:
  signed-out → sign-in gate; **authenticated free tier → inline "Upgrade to Pro" CTA** (routes to
  `account`, mirrors the Feed/Top-Plays gate); Pro+ → the existing draft flow. `hasReportAccess`
  mirrors backend `report_access`. New `ReportPanel.spec.ts` asserts all three states.
